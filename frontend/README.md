# Frontend for ChargeTrails
The frontend is built using React, with styling in CSS, and includes key components and assets necessary for the app's functionality.

## Key Features
- **User Authentication**: Integrated with Firebase for secure login and registration.
- **Dashboard**: Displays product tracking and other app data.
- **Image Upload**: Capture or upload receipt images.
- **Responsive Design**: Optimized for use on various devices.
- **Navigation**: Seamless transitions between landing, login, and dashboard pages.

---

## Technologies Used
- **Frontend Framework**: React
- **Styling**: CSS
- **Authentication**: Firebase
- **Assets**: PNG icons for app functionality
