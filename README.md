# ChargeTrails

Given Minerva University’s model of students visiting different rotation cities each semester, ChargeTrails aims to simplify the transition process of easing into new cultures by enabling access to data on where to buy various products, as recorded by previous cohorts who visited that city.

## Features

### Completed
- **Authentication**: User login and account management.
- **Data Extraction Workflow**:
  - Upload receipts as images.
  - Capture receipt images directly from the app.

### In Progress
- **User Database Setup**:
  - Save user data.
  - Retrieve and search user data.
- **Price Tracking**:
  - Monitor prices per product over time using graphs.
  - Analyze price trends by country or city.

### Planned
- **Retrieval Augmented Generation (RAG)**:
  - Identify the cheapest place a product was bought.
  - Provide tailored insights about specific products using RAG.
- **Social Features**:
  - Share product details and recommendations with other users.
  - Build a community aspect for sharing and interacting.

## Usage
- **Login/Register**: Access the app using your credentials.
- **Upload Receipts**: Upload or capture images of receipts for data extraction.
- **Track Prices**: View graphs and analytics for product prices over time.
- **Upcoming Social Features**: Share and view product recommendations from other users.
